v0.9.14 重点变化

本次发布包含4 项重点变化、8 项体验改进、6 项修复，以下是各部分的主要内容。

重点变化

新增带签名校验的应用内更新。OrcaTerminal 可以自动或手动检查更新，从公开发布通道下载对应安装包，完成校验、替换安装并重新启动。

体验改进

重新设计软件更新体验：使用带品牌元素的进度对话框、清晰的中文状态、独立的设置分组，并把 macOS 的检查更新入口放入应用菜单。

修复

取消正在建立的 SSH 连接时立即关闭等待界面，不再因等待后台线程停止而出现短暂卡顿。

从早期安装包到 SFTP、跳板机、端口转发和串口能力，OrcaTerminal 的每个版本都围绕真实远程工作流往前推进。

当前稳定版 2026-09-04

v0.9.14

重点变化

  • 新增带签名校验的应用内更新。OrcaTerminal 可以自动或手动检查更新，从公开发布通道下载对应安装包，完成校验、替换安装并重新启动。
  • SSH 端口转发现在会沿用主机保存的跳转路由；Windows 上的终端、SFTP 和端口转发也可以通过跳板机建立连接。
  • 主机编辑器现在会显示实时 TOTP 验证码和倒计时，同时保留完整 otpauth地址的编辑与复制能力。
  • 在支持的桌面环境中新增关闭到系统托盘和退出确认设置，并可从托盘菜单快速打开常用页面。

体验改进

  • 重新设计软件更新体验：使用带品牌元素的进度对话框、清晰的中文状态、独立的设置分组，并把 macOS 的检查更新入口放入应用菜单。
  • WebDAV 同步现在兼容 ETag 较弱或缺失的服务器，通过加锁版本控制继续保证冲突检测。
  • 内置 Inter 作为统一的界面字体，并在终端字体中新增 IBM Plex Mono、 Intel One Mono、Maple Mono 和 DejaVu Sans Mono。
  • 对连接对话框、启动页、Vault、SFTP、端口转发、菜单和终端控件统一了按压、悬停与焦点反馈。
  • 改进天气显示中的雨雪、闪电、云层、月亮、风力响应和动画节奏。
  • SSH 断开后标签页和回滚内容会保留在原位，并以内联状态展示按阶梯间隔进行的自动重连。
  • 新增 QNAP QTS 主机识别；刷新后保留当前 SFTP 面包屑目录；日期和天气文字会跟随界面语言。
  • macOS 发布包现在仅面向 Apple Silicon，不再发布 Intel 安装包。

修复

  • 取消正在建立的 SSH 连接时立即关闭等待界面，不再因等待后台线程停止而出现短暂卡顿。
  • 避免端口转发任务在关闭时仍被阻塞所导致的崩溃，并改进路由断开检测，让已停止的隧道及时释放本地端口。
  • 改进 WebDAV 设置、连接稳定性、冲突提示和窗口尺寸，兼容更多服务器实现。
  • SSH 重连后恢复远程工作目录，并更清楚地区分连接超时、主动取消和库错误。
  • 修复连接与同步对话框中的内容裁切和焦点状态问题，并让禁用的菜单项不再关闭菜单。
  • 软件更新窗口现在会按界面语言选择对应更新日志并正确渲染格式，不再显示 GitHub 自动生成的原始 Markdown。
稳定版 2026-08-19

v0.9.13

重点变化

  • 新增 Vault 工作区：为已保存的主机、SSH 密钥链和端口转发提供统一的导航区域，“关于”、快捷键和设置也嵌入为工作区页面。
  • 新增 SSH 密钥链：可以在应用自有的加密存储里生成、导入和重命名 SSH 密钥，把公钥安装到已保存的主机，并使用托管的密钥完成认证。
  • 新增基于 WebDAV 的加密设置同步，支持连接探测、安全保存凭据，并让设备相关的设置保留在本地。
  • SSH 新增 Windows 和 macOS 的 X11 转发。转发建立失败时会话仍保持连接。
  • 新增 Catppuccin Mocha、Tokyo Night、Latte 和 Gruvbox 终端主题。
  • 重新设计设置页面：分组自适应布局、用真实终端文字渲染的主题预览、自适应搜索，以及自动保存状态动画。

体验改进

  • 界面控件迁移到统一的设计系统：按钮、输入框、下拉框、复选框、菜单和对话框在所有页面保持一致的状态，工作区换用新的炭黑色调和 OrcaTerminal 产品图标。
  • 主机与 SSH 配置的编辑迁移到打磨过的侧边面板，未保存的草稿会保留。
  • 改进跳转路由编辑：支持拖拽插入提示、卡片移动动画、悬停显示删除按钮，滚动更稳定。
  • SFTP 传输采用流水线化的上传写入和下载读取，吞吐更高，上传失败会给出详细原因。
  • ZMODEM 传输可以直接由协议帧触发，不再需要手动从菜单发起。
  • 内置一致的应用字体：Windows 终端默认使用 Cascadia Mono，macOS 默认 Menlo，Linux 下字体字重渲染正确。
  • 已保存的主机会显示识别出的远程系统图标，包括国产 Linux 发行版。
  • 打磨菜单指针手势、下拉弹窗位置与悬停反馈、标签页关闭动画，以及传输指标对齐。
  • 改进自定义拖拽时 SFTP 文件表格的 VoiceOver 辅助功能。
  • Linux 字体探测与平台指标采样移出界面线程，状态栏图表改为批量刷新，界面更流畅。
  • SSH 凭据控件已翻译为中文。

修复

  • 加固终端转义序列处理：限制 OSC 和 CSI 缓冲长度，拒绝畸形的剪贴板与内嵌图片数据，并在 RIS 复位时完整还原状态。
  • 校验 ZMODEM 传输完整性，包括头和数据 CRC 以及接收位置；下载原子落盘，并拒绝超出限制的传输。
  • 加固 SFTP 下载对符号链接目录和路径逃逸的防护，下载文件原子提交。
  • 载入时修复无效的已保存配置（重复标识符、端口和帧配置），迁移失败时保留已保存的密钥。
  • 保留工作目录、远程路径和拖放文件名中的空白字符。
  • 在 Windows 和 macOS 上可靠上报本地、串口、SSH 和 Telnet 会话的结束原因。
  • 天气查询会为卡住的请求超时，并取消被新查询取代的请求。
  • 双因素认证拒绝畸形的 Base32 密钥，并让预留的验证码过期。
  • 串口会话结束后把 Linux 自定义波特率恢复为有效值。
稳定版 2026-07-01

v0.9.12

重点变化

  • 新增独立 Telnet 连接入口，可从启动页和应用菜单创建连接，并带有对应的连接处理和关闭动作。
  • 新增兼容 iTerm2 图片协议的终端内图片显示能力。内置的 imgcat 命令可以直接在终端里显示本地图片、管道传入的图片数据、从网络下载的图片，以及 WebP 图片。
  • 终端里的图片现在可以拖拽出来。如果图片来自本地 imgcat 文件，会尽量保留原始文件路径；如果图片来自管道、URL、远程 SSH 会话，或者原文件已经不可用，则会自动使用一个本地临时副本。
  • 状态栏新增天气入口，支持基于 IP 自动定位、中文城市与拼音搜索、详细天气弹窗，以及随天气变化的氛围效果。
  • SSH 会话现在会尽可能自动启用 OrcaTerminal 的 shell integration。远程标签页可以像本地终端一样更新标题和当前目录。
  • 把文件拖入远程终端时，现在可以先通过 SFTP 上传，再插入可用的远程路径。

体验改进

  • 传输进度弹窗现在会显示队列文件、剩余时间和更稳定的文件行，并改进滚轮交互。
  • 终端右键菜单新增分屏动作，分屏时也会更稳定地保留当前目录。
  • 新增终端铃声设置，并为 Linux 桌面内置 freedesktop 铃声音效。
  • 改进状态栏指标显示，包括更紧凑的尺寸、SVG 渲染的 CPU/内存/网络图标、主网卡速率，以及窗口恢复后的 CPU 状态保留。
  • 优化端口转发面板、连接路由控件、主题选择卡片、scrollback 控件、自定义滚动条、启动页头像和共享右键菜单行。
  • 应用界面文字新增内置 Inter 字体。
  • 降低空闲时的 CPU 唤醒，避免在不需要时持续刷新状态和监控字体变化。
  • 调整标签栏里的活动铃铛图标，让形状更均衡，不再显得过高。
  • 串口连接现在使用独立的 USB 风格图标，更容易和本地终端区分。
  • macOS 系统菜单已补充中文，包括“关于”“隐藏”“服务”“退出”等菜单项。
  • 改进 SFTP 拖拽反馈，包括更清楚的文件预览、更明显的拖放目标提示，以及取消传输时清理未完成上传。
  • 改进 Linux、Windows 和 macOS 打包流程，包括 Linux 默认 bundled Qt、更干净的 RPM 目录归属、插件 RPATH 修复、拆分 Debian Polkit 包、macOS TLS 插件，以及 Windows 图片和 shell integration 资源。

修复

  • 收紧 ZMODEM 邀请识别，避免普通终端输出误触发传输弹窗。
  • 修复 bash shell integration 提示符标记泄漏，并改进命令文本上报。
  • 修复中文等双宽字符上的光标重绘问题，让闪烁光标视觉上更居中。
  • 修复跨续接单元格选择双宽字符时的复制内容。
  • 修复 OSC 633 shell integration 对 UTF-8 路径和命令文本的解码问题。
  • 改进串口处理，使用原生后端，并隐藏 Windows 上实际不可用的串口。
  • Linux 串口功能使用的 Polkit 授权提示已补充中文。
  • 加强 SFTP 传输冲突处理，减少覆盖、重命名等场景下的困惑状态。
