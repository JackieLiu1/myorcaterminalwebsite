Current stable

v0.9.11 重点变化

这一版把 OrcaTerminal 从核心终端能力推进到更完整的跨平台桌面工具：新增串口会话、动态 SOCKS 转发，并补齐 Windows 与 macOS 发布包。

串口终端会话

支持直接打开串口设备，并保存常用串口配置。Linux 上也补充了串口访问授权流程。

动态 SOCKS 转发

SSH 连接可以作为动态代理使用，更适合需要临时访问远端网络资源的开发和运维场景。

跨平台安装包

新增 Windows 和 macOS 发布包，并在打包流程中加入更严格的发布前检查。

In progress

下一版预览

这些变化已经进入开发分支，但还没有作为稳定版发布。它们会让终端内图片、远程 shell integration 和日常细节更顺手。

  • 终端内图片显示

    内置 imgcat 命令可直接显示本地图片、管道数据和下载图片。

  • 图片拖拽导出

    终端里的图片可以拖出使用，本地文件会尽量保留原始路径。

  • SSH shell integration

    远程标签页可以更自然地更新标题和当前目录，体验更接近本地终端。

Version history

历史版本

从早期安装包到 SFTP、跳板机、端口转发和串口能力，OrcaTerminal 的每个版本都围绕真实远程工作流往前推进。

当前稳定版 2026-06-12

v0.9.11

重点变化

  • 新增串口终端会话、可保存的串口配置，以及 Linux 串口访问授权支持。
  • 新增 SSH 动态 SOCKS 转发能力。
  • 新增 Windows 和 macOS 发布包，并加强发布打包前检查。

体验改进

  • 降低运行过程中的内存保留，避免提前创建尚未打开的功能面板。
  • 改进终端渲染、内置字体回退、按钮、对话框和标签页细节。
  • 改进 SFTP 传输进度刷新，并把测试检查纳入发布打包流程。
稳定版 2026-06-03

v0.9.10

  • SFTP 会话新增跳板机支持。
  • 改进重连体验，支持指数退避重试，并提升临时断线后的恢复能力。
  • 缓存已打开的远程文件，让重复访问 SFTP 文件时更顺畅。
  • 传输进度弹窗现在会显示传输速度，退出应用时也会检查活动 SFTP 会话。
稳定版 2026-06-02

v0.9.9

  • 新增 ZMODEM 文件传输支持。
  • 新增左右分栏的本地/远程 SFTP 文件浏览器，支持拖拽传输、后台进度、文件菜单和冲突处理。
  • 新增 SSH 跳板机和 ProxyJump 支持，并提供路由编辑界面。
  • 重构 SSH 连接传输层，让分屏、端口转发和高输出场景下的响应更稳定。
稳定版 2026-05-26

v0.9.8

  • 新增类似 Chrome 的标签页拖拽排序，并带有回弹动画。
  • 支持把文件拖到终端里，自动填入文件路径。
  • 新增本地 shell integration，用于更新标签页标题和当前目录，并支持 bash 与 zsh 启动注入。
  • 改进 SSH 认证、保活、端口转发关闭流程和中键粘贴体验。
稳定版 2026-05-21

v0.9.7

  • 改进 SSH 会话所有权管理，让不同会话之间的隔离更清晰。
  • 在更多会话错误场景下保持远程转发可用。
  • 放宽保活断开阈值，减少慢网络环境下不必要的断连。
稳定版 2026-05-20

v0.9.6

  • 改进 Linux 打包，支持 bundled Qt、插件搜索路径和更简洁的安装布局。
  • 新增 bundled Fcitx Qt6 输入法插件，改善 Linux 输入法体验。
  • 当新输出进入 scrollback 时，保持当前查看位置稳定。
  • 改进终端边距、空白单元格选择、链接悬停刷新、SSH 保活和端口转发可靠性。
稳定版 2026-05-19

v0.9.5

  • 新增第一批 Linux 和 Windows 安装包，包括 RPM/DEB 包和 Windows NSIS 安装包。
  • 扩展终端兼容性，包括备用屏幕、括号粘贴、鼠标协议、OSC 8 链接和 OSC 52 剪贴板。
  • 新增应用与终端主题图标、双语构建文档，以及 Linux GitHub Actions 流程。
  • 改进性能，包括复用渲染缓存、缓存字体指标和更好的 Ctrl-C 中断处理。
